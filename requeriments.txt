# LOCUSTAF

## Sistema Web de Control de Asistencia Laboral

Versión MVP 1.0

---

# 1. DESCRIPCIÓN GENERAL

LOCUSTAF (Locus Staff) es una aplicación web desarrollada para facilitar el control de asistencia, registro de horas laborales y validación de ubicación de trabajadores mediante geolocalización.

El sistema está orientado inicialmente a pequeños empleadores que necesitan administrar empleados desde una única plataforma.

Ejemplos de uso:

* Personal doméstico
* Albañiles
* Niñeros
* Personal gastronómico
* Jardineros
* Empleados temporales
* Pequeños equipos de trabajo

---

# 2. OBJETIVO GENERAL

Desarrollar una plataforma web moderna, intuitiva, responsive y segura que permita administrar empleados, registrar asistencias y validar la ubicación laboral mediante GPS.

---

# 12. GEOLOCALIZACIÓN

La geolocalización es obligatoria.

Proceso:

1. Solicitar ubicación GPS.
2. Obtener latitud y longitud.
3. Obtener lugar asignado.
4. Calcular distancia.
5. Comparar con radio permitido.

Si la distancia es válida:

Asistencia registrada.

Si la distancia supera el radio permitido:

Mostrar mensaje:

"Usted se encuentra fuera del rango permitido."

No registrar asistencia.
